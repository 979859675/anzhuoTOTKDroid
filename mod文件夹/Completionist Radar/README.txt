Completionist Radar 1.1 - Tears of the Kingdom 1.4.3, TOTK recompilation (PC)
by TakeyaSaito

Shows what you have left to find on the in-game map. SPOILERS: that is the point.

- All Korok seeds you have not found, on the map and the minimap. Each one disappears when collected.
- Shrines before you discover them.
- Dragon Tears: a teardrop until the spot is found.
- Chests holding a Sage's Will (star), an Old Map (compass) or a piece of armor (chest), with the item's
  name when you hover it. The marker disappears when the chest is opened.
- Treasure spots from Old Maps stay as in the normal game: they appear once you have read the map.

INSTALL
1. Extract the zip into the "mods" folder next to the game, so you get mods\Completionist Radar\exefs and \romfs.
2. Start the game. The first start rebuilds the game code, which takes a few minutes, and then it starts again.

It works at every resolution and screen shape.

STEAM DECK / LINUX: if the mod says "not used", the automatic rebuild could not start. In Desktop Mode, run the setup
AppImage again and pick the same install folder. It skips the game extraction and builds the mod in.

REQUIREMENTS AND LIMITS
- Game version 1.4.3 and the TOTK recompilation. Built for recomp v0.3.7. Not tested on a Switch or an emulator.
- The icons are the game's own, reused from map stamps and shops, so the star looks like the star stamp but gold.
- Koroks show at the two closest map zoom levels. They can't be selected, so you can place a pin on top of one.
- Cave chests are marked at the chest's own position, which may not be the cave entrance.
- The mod does not change your save. Remove the folder to uninstall.
